Privacy Policy

Last updated: 30 April 2026

OP Auto Clicker is built around a simple privacy commitment: we collect zero data about you. This page explains exactly what we do and don't do — and what you can verify yourself.

The OP Auto Clicker software

The downloadable OP Auto Clicker application contains no networking code at all. It does not connect to the internet, send telemetry, check for updates, or transmit any data anywhere. You can verify this by inspecting our open-source code on GitHub or by monitoring network traffic while running the app.

The app stores its own settings locally in a small configuration file alongside the executable. Nothing leaves your computer.

The opauto-clicker.com website

This website is hosted on Vercel. We do not run any analytics, tracking pixels, or third-party scripts. The site loads:

  • Google Fonts (for the Inter typeface) — Google may log the request
  • Vercel's standard request logs — used for fraud prevention and billing only, retained briefly per Vercel's policy

We do not set cookies. We do not have an account system. We do not collect or process any personal data.

External links

Our pages link to external resources (Wikipedia, Microsoft documentation, VirusTotal, GitHub). When you follow those links, the destination's privacy policy applies — not ours.

Children's privacy

OP Auto Clicker does not knowingly collect data from anyone, including children under 13. The software runs locally and the website collects no personal information.

Changes to this policy

If this policy changes, the "Last updated" date at the top of this page will change too. Substantive changes will be noted in our GitHub commit history.

Contact

Questions about privacy? Open an issue on our GitHub repository.
