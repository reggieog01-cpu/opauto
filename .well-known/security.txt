# How to report a vulnerability
#
# 1. Open a Security Advisory on the GitHub repo (preferred — supports
#    private disclosure and CVE assignment).
# 2. Or email security@opauto.app with full details and a 5-day
#    response window.
#
# What we ask of you:
# - Give us reasonable time to investigate before public disclosure.
# - Don't access user data or systems beyond what's needed to
#   demonstrate the vulnerability.
# - Don't run automated scanners against opauto.app — they generate
#   false positives and noise. Submit findings from your own dev box.
#
# What you can expect from us:
# - Acknowledgment within 5 business days.
# - Patch within 30 days for confirmed vulnerabilities.
# - Public credit in the release notes (with your permission).
