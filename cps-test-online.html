What is an online CPS test?

An online CPS test is a browser-based tool that counts how many times you click your mouse (or tap your touchscreen) inside a fixed time window. The most popular test durations are 1, 5, 10, 30, and 60 seconds. The 5-second test — popularized by the Kohi Minecraft PvP server — is the competitive standard. The 10-second test balances peak burst and sustained speed. Longer windows (30–60 seconds) test endurance and rule out burst-only techniques like drag clicking. Every CPS test works the same way internally: JavaScript captures mousedown events on a target element, counts them for the test duration, then divides by seconds to compute clicks per second. Our free CPS test runs entirely client-side — no server call, no tracking, no signup. Results are shown instantly and can be shared as a permalink.
