Browser-only method (no download)

Cookie Clicker auto-click bookmarklet — one click, no install

If you're playing the browser version at orteil.dashnet.org/cookieclicker, you don't need to install anything. Drag this snippet into a browser bookmark, then click it once on the Cookie Clicker tab to start auto-clicking the Big Cookie.

The bookmarklet code

javascript:(function(){
  var c = document.getElementById('bigCookie');
  if(!c){alert('Open Cookie Clicker first');return;}
  if(window._cca){clearInterval(window._cca);window._cca=null;alert('Auto-click stopped');return;}
  window._cca = setInterval(function(){c.click();}, 10);
  alert('Auto-click started');
})();

The interval is set to 10 ms (about 100 CPS). Lower it to 1 for max speed during Click frenzies, raise it to 50 for idle mode. Click the bookmark once to start, click again to stop.

How to install it

  1. Right-click your browser's bookmark bar → Add page (Chrome / Edge / Brave) or New bookmark (Firefox)
  2. Name it Cookie Auto-Click
  3. Paste the entire javascript:(function(){...})(); snippet into the URL/Location field
  4. Save, then open Cookie Clicker in a new tab
  5. Click your new bookmark once to start auto-clicking, again to stop

Limitations: the bookmarklet only works on the browser version, not the Steam app. It can't trigger Golden Cookies (those spawn at random positions) and won't survive page refresh.
